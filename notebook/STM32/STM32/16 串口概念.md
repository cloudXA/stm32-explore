# USART/UART基础概念

## UART和USART

UART是异步串行通信；USART还可以支持同步模式。当前STM32与CH340、蓝牙、ESP8266之间使用的通常都是异步模式，所以学习时常把USART口简称为“串口”。

## 一帧数据怎么走

常见 `115200, 8-N-1` 表示：

```text
波特率：115200 bit/s
数据位：8位
校验位：None
停止位：1位
```

线路空闲通常为高电平。发送一个字节时，硬件依次输出起始位、8个数据位和停止位。收发双方的波特率、数据位、校验和停止位必须一致，否则会乱码或出现帧错误。

## 接线

```text
设备A TX → 设备B RX
设备A RX ← 设备B TX
设备A GND — 设备B GND
```

TX/RX要交叉并共地。还要确认电平制式：STM32模块间通常是3.3V TTL/CMOS UART；传统RS-232可能有正负电压，不能直接连接STM32，需要电平转换芯片。

## 全双工与两个方向

USART发送和接收是两条独立数据路径，因此可以同时进行：

```text
发送：内存中的字节 → USART发送寄存器 → TX引脚
接收：RX引脚 → USART接收寄存器 → 内存变量/数组
```

轮询、中断和DMA并不会改变导线上的UART协议，只是改变CPU如何把数据放入或取出USART寄存器。

## 三种接收方式

| 方式 | CPU表现 | 适合场景 |
|---|---|---|
| 轮询/阻塞 | 等待数据期间占用主流程 | 最小实验、调试 |
| 中断 | 数据到达后通知CPU处理 | 低到中等数据量、事件式程序 |
| DMA | 硬件自动在USART与数组间搬运 | 连续、高速、批量数据 |

## 排错顺序

1. 供电和共地。
2. TX/RX是否交叉。
3. 电平是否兼容。
4. 两端参数是否一致。
5. CubeMX引脚是否对应正确USART及复用功能。
6. 接收代码是否已启动，缓冲区是否越界，错误后是否重新启动。
7. 用逻辑分析仪查看真实字节，而不是只猜字符串编码。
