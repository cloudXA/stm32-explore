## 一、实验目的

本实验使用 STM32F103 的 DMA，把 SRAM 中的一段数据搬运到 USART1 数据寄存器，再由 USART1 从 PA9 引脚逐字节发送到电脑串口助手。

数据通路如下：

```text
uartTxBuffer（SRAM）
        │
        │ DMA1 Channel4
        ▼
USART1->DR 数据寄存器
        │
        │ USART1 TX
        ▼
PA9 引脚 → USB 转串口 → 电脑串口助手
```

DMA 负责从内存读取数据并写入 USART1，CPU 不需要像 `HAL_UART_Transmit()` 那样等待每个字符发送完成。

## 二、CubeMX 核心配置

### 1. USART1 配置

```text
Mode        : Asynchronous
Baud Rate   : 115200
Word Length : 8 Bits
Parity      : None
Stop Bits   : 1
TX Pin      : PA9
RX Pin      : PA10
```

对应常用串口参数为 `115200 / 8N1`。

### 2. USART1_TX DMA 配置

STM32F103 的 USART1_TX 固定映射到 DMA1 Channel4。本工程配置为：

```c
hdma_usart1_tx.Instance = DMA1_Channel4;
hdma_usart1_tx.Init.Direction = DMA_MEMORY_TO_PERIPH;
hdma_usart1_tx.Init.PeriphInc = DMA_PINC_DISABLE;
hdma_usart1_tx.Init.MemInc = DMA_MINC_ENABLE;
hdma_usart1_tx.Init.PeriphDataAlignment = DMA_PDATAALIGN_BYTE;
hdma_usart1_tx.Init.MemDataAlignment = DMA_MDATAALIGN_BYTE;
hdma_usart1_tx.Init.Mode = DMA_NORMAL;
hdma_usart1_tx.Init.Priority = DMA_PRIORITY_LOW;
```

各项含义：

| 配置项 | 含义 |
| --- | --- |
| `DMA_MEMORY_TO_PERIPH` | 从内存搬运到 USART1 外设 |
| `DMA_PINC_DISABLE` | USART1 数据寄存器地址固定，不能递增 |
| `DMA_MINC_ENABLE` | 每发送一个字节，内存地址移动到下一个字节 |
| `DMA_PDATAALIGN_BYTE` | USART 当前使用 8 位数据，因此外设宽度为 1 字节 |
| `DMA_MDATAALIGN_BYTE` | 发送缓冲区按照字节读取 |
| `DMA_NORMAL` | 发送完指定长度后停止，由程序决定何时再次发送 |

这里使用 `BYTE` 是正确的，因为串口配置为 8 位数据。`HAL_UART_Transmit_DMA()` 的长度参数表示需要发送的字节数量。

### 3. 关联 UART 与 DMA

```c
__HAL_LINKDMA(uartHandle, hdmatx, hdma_usart1_tx);
```

这条宏把 `huart1.hdmatx` 指向 `hdma_usart1_tx`。如果缺少关联，`HAL_UART_Transmit_DMA()` 无法找到对应的 DMA 通道。

### 4. 必须开启两个中断

```c
HAL_NVIC_SetPriority(DMA1_Channel4_IRQn, 0, 0);
HAL_NVIC_EnableIRQ(DMA1_Channel4_IRQn);

HAL_NVIC_SetPriority(USART1_IRQn, 0, 0);
HAL_NVIC_EnableIRQ(USART1_IRQn);
```

DMA1 Channel4 中断负责报告“缓冲区已经全部写入 USART”。USART1 中断负责报告“最后一个字节已经真正从 TX 引脚发送完成”。

## 三、发送缓冲区和状态变量

```c
#define UART_TX_PERIOD_MS 1000U

uint8_t uartTxBuffer[] =
    "USART1 TX DMA: data moved from SRAM to the serial port.\r\n";

volatile uint8_t uartTxComplete = 1U;
uint32_t uartLastTxTick = 0U;
```

### `uartTxBuffer`

它是一个已初始化的全局非 `const` 数组，因此运行时位于 SRAM。DMA 会直接读取这段内存，无需 CPU 逐字节复制。

DMA 正在发送时必须保证：

- 缓冲区仍然有效。
- 缓冲区内容没有被其他代码修改。
- 不能把一个已经退出函数的局部数组继续交给 DMA 使用。

### `uartTxComplete`

这个标志用于防止两次发送重叠：

- `0`：USART1 DMA 正在发送，不能再次启动。
- `1`：前一次发送已经完全结束，可以启动下一次发送。

变量在中断回调和主循环之间共享，因此使用 `volatile`，避免编译器把它当成不会改变的普通变量。

### `uartLastTxTick`

它记录上一次启动发送的系统毫秒计数，用于实现每隔 1 秒发送一次。

## 四、首次启动 DMA 发送

外设初始化顺序：

```c
MX_GPIO_Init();
MX_DMA_Init();
MX_USART1_UART_Init();
```

DMA 时钟应当在 USART 的底层初始化配置 DMA Channel4 之前开启，所以本工程先调用 `MX_DMA_Init()`，再调用 `MX_USART1_UART_Init()`。

首次发送代码：

```c
uartTxComplete = 0U;
uartLastTxTick = HAL_GetTick();

if (HAL_UART_Transmit_DMA(&huart1,
                          uartTxBuffer,
                          (uint16_t)(sizeof(uartTxBuffer) - 1U)) != HAL_OK)
{
    Error_Handler();
}
```

`sizeof(uartTxBuffer)` 包含字符串末尾自动添加的 `\0`，但串口不需要发送字符串结束符，所以长度减 1。

`HAL_UART_Transmit_DMA()` 是非阻塞函数。它只负责配置并启动 DMA，然后立即返回。DMA 发送期间 CPU 可以继续执行主循环中的其他任务。

## 五、主循环中定时重复发送

```c
while (1)
{
    if ((uartTxComplete != 0U) &&
        ((HAL_GetTick() - uartLastTxTick) >= UART_TX_PERIOD_MS))
    {
        uartTxComplete = 0U;
        uartLastTxTick = HAL_GetTick();

        if (HAL_UART_Transmit_DMA(&huart1,
                                  uartTxBuffer,
                                  (uint16_t)(sizeof(uartTxBuffer) - 1U)) != HAL_OK)
        {
            uartTxComplete = 1U;
            Error_Handler();
        }
    }
}
```

启动条件有两个：

1. 前一次 DMA 发送已经完成。
2. 距离上次发送已经过去 1000 ms。

`HAL_GetTick()` 是无符号计数，使用差值判断可以正确处理计数器溢出的情况。

## 六、DMA 和 USART 两级中断流程

### 1. DMA1 Channel4 中断

```c
void DMA1_Channel4_IRQHandler(void)
{
    HAL_DMA_IRQHandler(&hdma_usart1_tx);
}
```

DMA 传输计数变为 0 后进入这个中断。HAL 会关闭 USART 的 DMA 请求，然后开启 USART 发送完成中断，继续等待最后一个字节真正移出发送移位寄存器。

### 2. USART1 全局中断

```c
void USART1_IRQHandler(void)
{
    HAL_UART_IRQHandler(&huart1);
}
```

当 USART 的 `TC`（Transmission Complete）标志置位时进入该中断。HAL 会把 USART 状态恢复为 `HAL_UART_STATE_READY`，随后调用用户完成回调。

完整调用链为：

```text
HAL_UART_Transmit_DMA()
        ↓
DMA1 Channel4 搬运所有字节
        ↓
DMA1_Channel4_IRQHandler()
        ↓
HAL_DMA_IRQHandler()
        ↓
等待 USART 最后一个字节发送完成
        ↓
USART1_IRQHandler()
        ↓
HAL_UART_IRQHandler()
        ↓
HAL_UART_TxCpltCallback()
```

如果只开启 DMA1 Channel4 中断而没有开启 USART1 中断，通常会出现：第一次数据能够发出，但 `huart1.gState` 一直停留在忙状态，第二次调用返回 `HAL_BUSY`。

## 七、发送完成回调与 LED 翻转

```c
void HAL_UART_TxCpltCallback(UART_HandleTypeDef *huart)
{
    if (huart->Instance == USART1)
    {
        HAL_GPIO_TogglePin(GPIOB, GPIO_PIN_8);
        uartTxComplete = 1U;
    }
}
```

回调中完成两件事：

1. 翻转 PB8 LED，直观表示一次 DMA 发送已经完整结束。
2. 将 `uartTxComplete` 置 1，允许主循环在时间到达后启动下一次发送。

PB8 初始配置为高电平。如果开发板 LED 是低电平点亮，那么第一次 DMA 发送结束后 PB8 变为低电平，LED 点亮；之后每秒亮灭切换一次。

把 LED 翻转放在完成回调里，比放在启动发送之前更能证明 DMA 中断、USART TC 中断和 HAL 回调链路都正常工作。

## 八、与阻塞式串口发送的区别

阻塞发送：

```c
HAL_UART_Transmit(&huart1, data, length, HAL_MAX_DELAY);
```

调用期间 CPU 会等待整个数据发送完成。

DMA 非阻塞发送：

```c
HAL_UART_Transmit_DMA(&huart1, data, length);
```

函数启动 DMA 后立即返回，CPU 可以执行其他任务，完成时由中断和回调通知。

之前用于 `printf()` 重定向的 `fputc()` 如果内部调用 `HAL_UART_Transmit()`，仍然属于逐字符阻塞发送，并不会自动使用 USART DMA。

## 九、预期实验现象

串口助手设置为 `115200 / 8N1`，每秒应收到一行：

```text
USART1 TX DMA: data moved from SRAM to the serial port.
```

同时 PB8 LED 每完成一次发送就翻转一次，因此大约每秒切换一次状态。

程序已经使用 ARM Compiler 6.24 完整编译验证：

```text
0 Error(s), 0 Warning(s)
```

## 十、常见问题排查

### 1. 第一次能发送，后续不再发送

重点检查 USART1 全局中断是否开启，以及中断函数中是否调用：

```c
HAL_UART_IRQHandler(&huart1);
```

### 2. `HAL_UART_Transmit_DMA()` 返回 `HAL_BUSY`

说明前一次发送还没有完全结束。不要在发送期间再次使用同一个 `huart1` 启动发送，应通过完成回调设置状态标志。

### 3. 串口没有任何输出

依次检查：

1. USART1 波特率和串口助手是否一致。
2. PA9 是否连接到 USB 转串口模块的 RX。
3. 两端 GND 是否共地。
4. DMA1 时钟是否已经开启。
5. USART1_TX 是否映射到 DMA1 Channel4。
6. `__HAL_LINKDMA()` 是否已经执行。
7. DMA1 Channel4 中断是否开启。

### 4. 输出乱码

检查波特率、系统时钟、数据位、停止位和校验位。当前工程使用 `115200 / 8N1`。

### 5. LED 不闪但串口能输出

检查 PB8 是否连接到 LED、LED 的有效电平以及 GPIO 是否配置为推挽输出。也可以用万用表或逻辑分析仪观察 PB8 电平。

### 6. 修改缓冲区后偶尔出现混乱数据

DMA 发送期间不能改写同一个缓冲区。如果需要连续发送动态内容，可以使用两个缓冲区进行乒乓切换，或者等完成回调到来后再修改。

## 十一、核心认识总结

1. USART1_TX 使用 DMA1 Channel4，把 SRAM 数据自动写入 USART1 数据寄存器。
2. 串口为 8 位数据，所以 DMA 的内存和外设宽度都配置为 `BYTE`。
3. 内存地址递增，USART 数据寄存器地址固定。
4. DMA 发送是异步的，缓冲区必须一直有效，并且发送期间不能修改。
5. 普通模式下既需要 DMA1 Channel4 中断，也需要 USART1 全局中断。
6. 完成回调表示最后一个字节已经真正发送完成，此时才能安全地开始下一次发送。
7. 在完成回调中翻转 LED，可以同时验证 DMA、USART 和中断回调链路。
