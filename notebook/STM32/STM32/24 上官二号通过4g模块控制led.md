# EC03-DNC通过4G控制LED：与ESP8266方案的差异

不止手机会插 SIM 卡，但你的判断有一半是对的：

> 如果你的目标只是学习 STM32 的串口、TCP和网络控制LED，那么现在没必要为了4G模块额外买卡、流量和公网服务器。ESP8266更适合当前学习阶段。

4G模块更多用于“设备不方便接入Wi-Fi，但又必须远程联网”的场景，例如：

- 共享单车、车辆定位器和车载终端
- 自动售货机、充电桩
- 快递柜、广告屏
- 农田、水库和气象监测设备
- 无人值守的工业设备
- 电表、水表和环境监测站
- POS机及移动支付终端
- 户外摄像头
- 电梯远程监控
- 工地设备和物流追踪器

这些产品内部可能使用普通SIM卡，也可能使用焊接在电路板上的贴片卡（eSIM/eUICC）或企业物联网卡，所以用户未必能看到卡槽。

## 4G模块真正解决的问题

ESP8266依赖附近存在可用Wi-Fi：

```text
STM32 → ESP8266 → 路由器 → 互联网
```

4G模块不需要现场路由器：

```text
STM32 → 4G模块 → 基站 → 互联网
```

例如一台安装在农田里的水位检测器，附近没有Wi-Fi，但有移动信号，这时4G模块就很有价值。

## 对你当前学习的建议

目前继续使用ESP8266更合适，因为它已经足够让你学习：

- UART中断接收
- AT指令
- TCP客户端与服务器
- 字节流解析
- 断线重连
- 应用协议
- GPIO远程控制

等你把这些掌握以后，再了解4G只需要补充：

```text
Wi-Fi入网过程
     ↓ 换成
SIM卡注册、运营商网络和公网连接
```

STM32侧很多核心思想仍然一样：

```text
串口收数据
→ 识别连接状态
→ 提取业务数据
→ 解析led1/led0
→ 操作GPIO
```

如果你手头已经有EC03-DNC和SIM卡，可以做一次4G透传实验，理解“设备跨局域网远程联网”即可，没有必要一开始深入运营商网络。

如果没有SIM卡，我建议先放下4G项目，沿着ESP8266继续做三个更有学习价值的功能：

1. TCP断线自动重连。
2. 增加 `status?`、`pwm=50` 等应用协议。
3. 将单字节中断升级为DMA加空闲中断。

这三项对于从前端转嵌入式，比现在研究4G入网更划算。

## 关键纠错：不能直接使用同一套ESP8266命令

EC03-DNC属于串口转4G的Cat.1数传模块/DTU，虽然也通过UART与STM32通信并支持TCP、UDP、MQTT，但它的AT指令、入网流程、连接状态文本和透传配置都由亿佰特固件定义，不是ESP8266的ESP-AT命令集。

可以复用的是软件架构：

```text
UART接收
→ AT响应解析
→ 连接状态机
→ TCP字节流解析
→ led1/led0业务
→ GPIO控制
```

不能直接复用的是：

```text
AT+CWJAP
AT+CWMODE
AT+CIPSTART
WIFI GOT IP等ESP8266专用命令/响应
```

应按EC03-DNC指令手册重新实现驱动层，不能只把TX/RX接到原位置就期望原程序工作。

## 是否必须插SIM卡

要通过蜂窝网络传输数据，通常必须安装已开通数据业务、频段和运营商可用的Micro SIM/物联网卡，并正确安装天线。还要根据运营商配置APN；PIN锁、欠费、无信号或未附着网络都会导致TCP无法建立。

## PC开TCP Server为什么仍可能连不上

4G模块不在PC的Wi-Fi局域网内：

```text
PC私网地址 10.x/192.168.x
≠ 互联网可访问地址
```

EC03从运营商网络发起连接时，不能直接访问PC的 `10.154.61.205:8880` 这类私网地址。若要让模块连到PC服务器，需要公网可达的IP/域名和端口映射，或让PC与设备加入同一VPN；更常见的学习方案是租用公网云服务器，让EC03和PC都作为客户端连接服务器。

## EC03-DNC硬件要点

根据该型号厂商资料：默认UART通常为115200bps，串口逻辑默认为3.3V；VCC供电范围为5～18V，5V发射时典型电流约300mA。具体板卡仍以实物版本和手册为准。

- 不要把STM32的3.3V引脚直接当作模块VCC电源。
- VCC供电与4V2电池供电引脚不能同时使用。
- TX/RX交叉、GND共地，先单独验证 `AT` 和模块信息查询。
- 蜂窝发射存在电流突变，电源余量和去耦不足会造成重启/掉线。

## 推荐实验顺序

1. 不接STM32，先用USB-TTL与厂商配置工具确认模块、SIM、天线和网络注册正常。
2. 查询并记录实际UART参数、IMEI/ICCID、信号质量、注册状态和APN。
3. 让模块连接一个公网测试TCP Server，验证双向透传。
4. 再接STM32，仅做原始字节回显，确认电平和波特率。
5. 按EC03手册实现命令/响应状态机。
6. 最后把通用的 `led1/led0` 解析和GPIO业务接上。

这样分层后，如果失败，可以判断是供电/SIM注册、4G到服务器、UART，还是STM32业务解析的问题。
